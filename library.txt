Here are the main features for the simple library management system:

1. **User Authentication:** Both User 1 and User 2 can securely log in to access their assigned features.
2. **Book Catalog Search:** Both users can search for available books by title, author, or category.
3. **Book Inventory Management:** User 1 can add, update, or remove book records from the system.
4. **Borrowing and Returning:** User 1 can issue books to User 2 and record returned items.
5. **Account Dashboard:** User 2 can view their currently borrowed books, due dates, and borrowing history.
6. **Fine Tracking:** User 1 can calculate and collect fine payments for overdue books.
